# 🍌 Flopgram — Share Your Worst Moments

**Flopgram** is a fun, chaotic social media parody website where every normal feature is transformed into a hilarious rage-bait experience. From disappearing buttons and fake notifications to impossible mini-games, the platform is designed to entertain users by testing their patience.

## ✨ Features

### 📸 Social Media Feed
- View sample posts with funny captions.
- Upload images and create posts with captions.
- Apply random, intentionally terrible photo filters.
- Interact with banana-themed like buttons that dodge the cursor.

### 🤡 Rage-Bait Features
- Login button that moves away when you try to click it.
- Funny login errors and fake loading screens.
- Signup with unusual password requirements.
- Frustrating CAPTCHA and Terms & Conditions interactions.
- Random follower loss and fake notifications.
- Reversing scroll direction and unexpected screen movements.
- Randomly swapped Post and Cancel button labels.
- Repeated cookie consent pop-ups.
- Fake hacking alerts and humorous password recovery.
- Seven-round account deletion prank.
- Panic button with massive confetti effects.

### 🎮 Arcade of Despair

Play six intentionally frustrating mini-games:

- 🔨 Whack-a-Follower
- 🍌 Catch the Banana
- ✊ Rock Paper Scissors
- 🔢 Guess the Number
- ⚡ Reaction Test
- 🧘 Stay Still

### 🧰 Normal Features™ (Ruined)

Experience familiar social media features with unexpected twists:

- 🔍 Search
- 🔔 Notifications
- 🌙 Dark Mode
- ⚙️ Settings
- 💬 Comments
- 👥 Follow Suggestions
- 📤 Share
- ✏️ Edit Profile
- 🔮 Fortune Teller

### 🧑‍🎤 Profile and Interactive Elements
- Sir Flops-a-Lot, an interactive mascot with moving eyes and sarcastic messages.
- Funny achievement badges.
- Simulated support chatbot.
- Unexpected volume slider behavior.
- Language modes: English, Pirate, Potato, and Backwards.
- Judge Mode activated using the **J** key.
- Hidden Calm Mode activated with the Konami code: `↑ ↑ ↓ ↓ ← → ← → B A`.
- Floating navigation with Home, Post, Logout, Games, Chat, Delete, and Panic options.

## 🛠️ Technologies Used

- **HTML5** — Website structure
- **CSS3** — Styling, animations, layouts, and visual effects
- **Vanilla JavaScript** — Interactive functionality and game logic
- **FileReader API** — Local image preview functionality

## 🚀 Getting Started

### Prerequisites

You only need a modern web browser. No backend server or package installation is required for the current demo.

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder.

3. Locate the main HTML file, such as `index.html`.

4. Open it in your web browser.

Alternatively, open the project in Visual Studio Code and use the **Live Server** extension to run it locally.

## 🎯 How to Use

1. Open Flopgram and experience the chaotic loading screen.
2. Try the login and signup options.
3. Explore the sample social media feed.
4. Upload an image and create your own post.
5. Test the banana-themed like buttons.
6. Explore the Arcade of Despair mini-games.
7. Open Normal Features™ (Ruined) and try the available interactions.
8. Use the floating navigation to explore different sections.
9. Press **J** to open Judge Mode.
10. Enter the Konami code to activate Calm Mode temporarily.

## 🎨 Design Highlights

- Bright, playful colors and comic-inspired styling.
- Wobbly cards, animated buttons, and moving elements.
- Random pop-ups, confetti, and toast notifications.
- Humorous text and intentionally unpredictable interactions.
- Responsive layout for different screen sizes.
- Reduced-motion CSS support for users who prefer less animation.

## ⚠️ Important Notes

- Flopgram is a **front-end parody project**, not a production social networking platform.
- Login and signup are simulated and do not provide real authentication.
- Posts, followers, and profile information are not stored in a backend database.
- Uploaded images are processed locally in the browser and are not uploaded to a server.
- Many features are intentionally designed to behave unpredictably for comedic effect.
- Do not enter real passwords or sensitive personal information.
